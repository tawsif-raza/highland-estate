# 🏔️ The Highland Estate

A **luxury coffee-estate resort landing page** — engineered to feel like a five-star hospitality brand.

## ✨ Highlights

- **Cinematic hero** — a full-screen entrance that sets the mood before the first scroll
- **Curated sections** — rooms, estate experiences, coffee & gallery, each with its own rhythm
- **Smooth-scroll storytelling** — the page reads like a journey through the estate
- **Mobile-first & fully responsive** — polished on every screen size
- **Optimized fonts & assets** — `next/font` (Geist) for crisp, fast typography

## 🚀 Getting Started

```bash
git clone https://github.com/tawsif-raza/highland-estate.git
cd highland-estate
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — the page auto-reloads as you edit.

| Layer      | Technology          |
